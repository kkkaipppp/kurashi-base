# 日本語：機能を説明しない、操作を分かるようにする

画面に表示する日本語すべてを抽出し、動詞/名詞のルールを作る。初心者が「押したら何が起こるか」を予測できること。重要な場面は動作を示す。

| 旧/不自然な表現 | 改善案 |
|---|---|
| 今月あと使える | 今月の残り予算 |
| 今日のナビ | 確認したいこと（タスクの場合は「今日やること」） |
| くらしの気づき | 支出の変化 |
| まずは3つだけ | はじめにやること |
| 画像を見ながら記録 | レシートを見て入力（OCR未実装時） |
| 資格・科目 | 資格の学習 |
| 目標時間（時間） | 目標の勉強時間 |
| Googleカレンダーで開く（まだ登録していない） | Googleカレンダーに追加する |
| ナビ | 行き方を調べる |
| 検索実行 | Webで調べる |
| 参考書のリンク | 参考書を探す |
| 勉強時間のおすすめ | 勉強時間の目安 |
| リンク済み（外部候補を開いただけ） | 外部サイトで登録してください |
| バックアップファイルを書き出しました（完了未確認） | バックアップの保存を開始しました。ファイルを確認してください |

禁止：API、同期、ステータスなどの開発用語の安易な表示／検索サイトへの送信が未実施なのに「調べました」／タグ未登録の広告を「おすすめ本」と誤認させる／空カードと長文のオンボーディング。

文言監査はコードから抽出し、修正前後の一覧を保存。初見ユーザー5名に「このボタンで何が起こると思うか」確認して4名以上が一致すること。実際の動作と一致しない文言は不合格。
