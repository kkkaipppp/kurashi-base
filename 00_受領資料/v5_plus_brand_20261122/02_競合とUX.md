# 競合UX調査の使い方（2026-11-22確認）

| アプリ | 公式に確認できる特徴 | 取り入れる原則 |
|---|---|---|
| TimeTree | 予定作成、今日に戻る、予定の場所・URL・メモ・チェックリスト、下部タブの整理 | 月/週/日と予定詳細が自然につながり、追加時の入力を短くする |
| Lifebear | カレンダー・ToDo・ノート・日記を一元化 | 日付の下に予定とタスクをまとめて見せる |
| Googleカレンダー | タイトルと日時から作成、場所・説明・終日など詳細を追加可能 | 最小入力で保存し、必要なら詳細を追加 |
| Zaim | 手入力・レシート・履歴・カレンダー・予算の見通し | 残り予算と記録の速さを最優先 |
