# 実画面のキャプチャ指示（Claude Code用）

1. `cd app && npm ci && npm run dev` を起動する。
2. Playwrightなどで375x812と390x844のviewportでアクセス。プレビューと混同しないよう、`REAL_...png` として保存。
3. 1) 新規状態のホーム、2) サンプル入力後のホーム、3) カレンダー、4) 予定詳細、5) 予定編集、6) 復元設定、の6画面を撮る。
4. 保存対象はプロジェクトのプレビュー用ディレクトリのみ。個人情報の入った実データをスクリーンショットに含めない。
5. 画像内の日本語、折り返し、見切れ、見出しの情報量を確認。iPhoneのSafariで同等の実機確認が必要。
6. 静的プレビューとの差異を報告。実撮影できなかった場合は画像を偽造せずNOT_RUN。
