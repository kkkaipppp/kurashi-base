# 現在画面の画像について

`screen_*_code_preview.png` はv5のソースを読み、文言と主要ブロックを再配置してブラウザで撮影した **コード準拠の簡易プレビュー** です。
**Next.jsアプリを起動した実画面のスクリーンショットではありません。**

正確なUIの確証として使わず、実機を起動した際にスクリーンショットを撮影し、違いをレビューしてください。

現行v5ソースの基本構成:
- ホーム: ロゴ/β表記→今月の残り予算＋今日の支出→今日の予定（なければ次の予定）→必要時のみ今日やること→初回ガイド/補足情報→下部5アイテム（ホーム、カレンダー、＋、振り返り、メニュー）。
- カレンダー: 月表示／支出収入／日付セル・期限表示／選択日の予定・支出・収入。
- 予定: 予定名と日時は必須に近く、その他は「詳細を追加」で展開。予定詳細では場所・持ち物・Googleマップ/カレンダーへの外部導線がある。
