# 2時間版・受入ゲート

## P0：必須の確認（実施結果を DELIVERY_REPORT.md に記載）
1. アプリ起動・主要4画面遷移・375pxで横スクロールなし
2. 支出を新規登録→ホーム/カレンダー/履歴に反映→リロード後も残る
3. 支出編集で集計が再計算、削除後も再計算
4. 収入登録で支出と混同せず収支表示に反映
5. 予定を追加/編集/削除→カレンダーと今日の予定に反映
6. 月を切り替えて該当月だけを集計。年跨ぎも正しい
7. 金額未入力/0/負数/非数値を安全に拒否
8. 不正な日付/空の必須項目を安全に拒否
9. 連続タップで同一レコードを二重登録しない
10. 削除時に確認できる。キャンセルでデータが残る
11. 初回データなしで画面が壊れず、追加導線が見える
12. 保存先利用不可/破損データ時にクラッシュせずエラー案内
13. 日本時間の日付がUTC変換で前日にならない
14. 固定費を実装した場合、繰り返しで勝手に重複計上しない
15. 画像取込がある場合、確認前に支出を自動確定しない
16. `npm run build` と型チェックの実行結果を記録

## P1：時間が許せば
17. JSONエクスポートを再読込できる
18. 復元前プレビュー/キャンセルが機能する
19. 重複候補の警告とユーザー選択がある
20. カテゴリ/支払方法で絞込できる
21. 補助カード表示ON/OFFが維持される
22. 画像が不正形式/巨大サイズでも安全に扱う
23. キーボードだけで基本フォーム操作が可能
24. 画面更新・戻る操作で意図せずデータ消失しない

判定は PASS / FAIL / NOT_RUN / NOT_IMPLEMENTED を厳密に使う。未実施をPASSにしない。120件カタログは今後の品質改善用の検討観点であり、今すぐ全件合格を要求しない。
