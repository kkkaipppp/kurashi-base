# 暮らしベース — 独立新規開発スターター v2

**目的**：既存コードを移行せず、家計と予定を中心とした生活プラットフォームを新規開発する。まず主要画面・主要機能が動く大枠を完成させ、以降は利用者と反復改善する。

## Claude Codeに渡す
このZIPを新規作業フォルダに展開し、`14_CLAUDE_CODE_START_HERE.md` の内容をClaude Codeに貼る。

## 同梱物
01〜12：製品ビジョン、要求、UX、品質、ロードマップ、機能・画面・データ・受入仕様、実装計画（既存の初期仕様）
13：Phase 1の開発優先順位・スコープ境界
14：Claude Codeの初回指示
10_TEST_CASE_CATALOG_120.csv：120件のテスト観点（詳細手順・実測は実装後に補完）
assets/reference_mocks/：ホーム、カレンダー、支出登録、画像取込の参考SVG 4点

## 重要
参考SVGは**本パッケージ用に新規作成した仮ワイヤーフレーム**。元のアプリのスクリーンショットや元の画面モックは入っていない。実際のモックがあれば置き換えて優先する。

旧仕様にある「全24ケース合格＝ベータ公開」等の厳格な基準は、**公開時**に適用する。Phase 1の最初の到達点は「主要機能が動く開発版」であり、公開済みと混同しない。
