# Claude Code実行用プロンプト（コピーして使用）

このディレクトリを**独立した新規製品「暮らしベース」**の唯一の要求インプットとして扱い、ゼロから開発してください。既存のソースコード、リポジトリ、実装履歴、環境設定を前提にせず、新しいプロジェクトを作成してください。

1. READMEと01〜11のMarkdownを読み、製品ゴール・必須機能・検証対象・将来構想を区別してください。
2. `assets/mocks/` の画面モックを正本として画面台帳・対応表を作り、見た目・操作・遷移を再現してください。モックが無い場合はその不足を報告し、推測で再現済みとしないでください。
3. 要件ID→画面ID→データ項目→テストIDの対応表を作ってください。
4. OCR、iOSショートカット、通知自動取得、ウィジェットの実現可能性を検証し、Web/PWAで不可能な機能は代替策を提示してください。
5. 技術構成をADRに記録し、独立した新規コードベースを構築してください。
6. 必須機能を優先順位順に実装し、保存・重複・復元・集計のデータ品質を守ってください。
7. 10_ACCEPTANCE_TESTS.mdを自動テストと手動テストへ落とし込み、実行証跡を保存してください。未実施をPASSと記載しないでください。
8. 各フェーズ終了時に「実装内容・テスト・モック差分・未解決・次の作業」を報告してください。

最初は実装に突入する前に、画面モックの有無、仕様の不確定箇所、技術検証項目、フェーズ別WBS、MVP受入条件をまとめてください。重大な仕様の分岐以外は合理的な仮説を明記して進めてください。
