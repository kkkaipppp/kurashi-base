# 画面実装マップ（参考モック4枚付）

`assets/reference_mocks/01_home.svg` → ホーム：残額カード、今日の予定、支出追加・画像取込、最近の支出。残額は「予算−当月支出」と明記。予算未設定時は「未設定」。

`02_calendar.svg` → カレンダー：月切替、日付選択、予定と支出を区別して同日に表示、日別一覧。月末・年跨ぎ・当日強調を確認。

`03_expense.svg` → 支出登録：金額（整数、正）、日付、カテゴリ、支払手段（任意）、メモ、保存/編集/削除。収入も登録できる導線を用意。入力値を保持したままエラーを説明。

`04_import.svg` → 画像取込：画像選択、プレビュー、抽出候補（可能なら）、金額・日付・店名の確認編集、重複候補の表示、保存。自動で確定登録しない。

追加画面：予定編集モーダル、固定費一覧・編集、取引履歴、設定/バックアップ。下部ナビはホーム・カレンダー・履歴・設定を基本とし、支出追加は目立つCTAにする。

## 最小デザイン基準
- モバイルファースト、375/390/430pxで確認。デスクトップは中央最大幅レイアウトでよい
- 操作ボタン44px程度のタップ領域、フォームラベル、フォーカス可視化、コントラストを確保
- 数字は桁区切り、日本円、日付は日本ローカル日付を基本にする
- 実際の旧アプリ画面はこのZIPに含まれない。提供SVGは参考ワイヤーフレームであり完全一致を要求しない
