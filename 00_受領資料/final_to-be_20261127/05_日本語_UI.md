# 最終日本語レビュー
メニュー名は名詞、操作は動詞、状態は事実。短くするために意味を失わない。用語辞書は文脈別に適用し一括置換禁止。その他→メニュー、予定タブ→カレンダー、計画内の予定は予定。契約・固定費は入口名、支払いの正本は共通。共同計画の入口は「みんなで計画する」、機能名は日程調整/アンケート。曖昧な「反映」は具体的な反映先を示す。
# 画面別の標準文言
ホーム: 今日の予定／やること／今月の残り予算／次の支払い／確認すること。全員が回答しました、忘年会の日程を決める。未記録なら「まだ記録がありません」。
カレンダー: 今日／月・週・日・年／表示する内容／日程未定／期限なし／仮の予定／繰り返し／行き方を調べる／出発の目安／予定が重なっています。空き時間は「予定が入っていない時間」。
追加: 支出を記録／収入を記録／予定を追加／やることを追加／メモ／貼り付けて追加／前の記録から追加／下書き／保存。写真の自動解析がない場合は「写真を見ながら入力」。
家計簿: お金の記録／支出の内訳／収支の推移／残り予算／給料日からの予算／年に数回の大きな支出／次の支払日／月末の残高見込み／欲しいもの／買う前に確認／自分の負担額／返してもらうお金／返すお金／返金待ち／会社の経費／振替／残高を確認。予算・残高・収支・純資産・見込み・確定支払いを混同しない。
計画: 計画を作る／飲み会・集まり／旅行／引っ越し／買い物／出張／転職／自由に作る／過去の計画。次にやること／日程を決める／お店を決める／予約する／みんなに知らせる／お金を精算する。回答リンクを作る／回答期限／回答結果／まだ回答していない人／回答をお願いする／日程を決め直す／受付を終了する。みんなに聞く／質問を追加／1つ選ぶ／複数選ぶ／自由に書く／名前を表示しない（閲覧者範囲を明示）。お店を探す／お店を比べる／ホテルを比べる／航空券を比べる／物件を比べる／商品を比べる／応募先を比べる／これに決める。旅行の日程／移動・宿泊／予約情報／持ち物／旅行の予算／かかったお金／旅程を共有。引っ越す日／内見の予定／初期費用／毎月かかるお金／住所変更。購入金額／維持費／注文情報／保証・返品。
目標: 達成したいこと／達成したい日／途中の目標／計画を見直す／いったん休む／再開する。資格は勉強した時間・勉強を記録・申込締切・教材・受験結果。貯金は貯めた金額・貯金の記録。読書は読んだ本、運動は運動した回数。自由目標は単位・指標をユーザー設定。
資産: 資産一覧／借入・ローン／純資産／評価日／資産の推移／年間投資枠／残りの投資枠／非課税保有限度額。手入力なら「銀行・証券会社とは連携していません」。
契約: 契約名／契約先／支払い頻度／更新日／解約の締切／保証期間／支払い予定も作る。健康: 通院／健康診断／薬の記録／体調／測定記録／医療費。メモ: メモを書く／上に固定／タグ。書類: 書類名／種類／有効期限／保管場所／添付ファイル（対応時のみ）。
設定: ホームの編集／表示する機能／並び替え／カテゴリの編集／タグ／よく使う入力／通知／外部サービス／データを書き出す／データを取り込む／バックアップを作る／データを復元／保存容量／最初の表示に戻す。非表示は削除ではない。
# 状態と例外
計画: 検討中・準備中・完了・中止。日程: 回答受付中・日程確定・受付終了。予約: 未予約・予約済み・キャンセル済み（外部確認なしで予約済みにしない）。目標: 取り組み中・達成・休止中・中止。支払い: 支払い予定・一部支払済み・支払済み。精算: 未精算・一部精算済み・精算済み。同期: 未送信・反映待ち・反映済み・失敗。
エラーは原因が分かる範囲で、影響と次の行動を表示。「保存できませんでした。入力内容は残っています」は実際に残る場合のみ。「暮らしベースには保存しました。外部カレンダーには追加できませんでした。」は部分成功時のみ。「全員が参加できる日はありません」「全員の負担額の合計が支払額と一致していません」「このリンクからは回答できません。作成者に確認してください」。匿名、共有範囲、不可逆削除、金額計算、データ消失は説明を残す。
# ヘルプ・通知
目的別: 家計簿だけ使いたい／友達と日程を決めたい／お店の希望を聞きたい／旅行をまとめたい／資格の勉強を記録したい／画面を変えたい／機種変更したい。各機能に手順・実画面・注意・復旧を対応。通知は「忘年会：全員が回答しました」「ホテルの無料キャンセルは明日まで」等。送信・権限の実態を明示。過剰な挨拶、励まし、インサイト、スマート、管理機能、処理済み、実行済みを避ける。金額・日付・時刻の共通フォーマット、読み上げラベル、文字切れを検査。
