## 4. 確認したこと
- 320／375／390／430px：ホームの最初の画面で「今月の残り予算・今日の予定・今日やること」が見える（320×700 で確認）。横のはみ出しなし（14画面×4幅）
- シンボルを 200px・32px・16px で表示：形が崩れない。16px では窓の色の区別は難しいが、家の形は分かる
- iPhone 用アイコン（/apple-icon）：PNG 180×180 が作られる（本番ビルドで静的に生成）
- 見張りテスト：`tests/copy-v5.test.ts`（表示名がくらしベースにそろっていること、旧名を画面に出さないこと）
