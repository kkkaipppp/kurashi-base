## 決めごと（To-Be 03「現金移動、個人負担、立替債権を区別」から）
1. 立替（友達の分も払った）：払った総額のうち、自分の分だけを支出に数える。残りは「返してもらう分」で、支出にも収入にも数えない
2. 経費（会社に請求する）：全額を「返してもらう分」にして、支出に数えない（入金されたら精算）
3. 精算（返してもらった・自分が返した）：お金の移動だけで、収支に数えない。返してもらう分を減らす
4. どの集計も「金額」と「数え方」だけを見る今の作りを保つ（返金と同じやり方。あちこちに分岐を入れない）

## 形の案（どれも省略できる項目を足すだけ。古いバックアップはそのまま読める）
- `Transaction.share?: { mine: number; kind: "advance" | "expense" }`
  - advance＝立替（`mine` は自分の分、0 以上・総額以下）／expense＝経費（`mine` は 0）
  - 保存のときに、元の総額を控え、`amount` を自分の分にする（返金の `refundGross` と同じ考え方）か、`amount` は総額のまま集計で `mine` を使うかを選ぶ → 論点 P-1
- `Transaction.settles?: string`：精算の記録が、どの立替・経費を返したか（返金の `refundOf` と同じ形。収支に数えない）
- 「返してもらう分」の残り＝立替・経費の（総額 − 自分の分）− 精算の合計。0 未満にしない

## 画面の案（自分用）
- 支出の入力：「立替・経費」を詳細の中に（自分の分の金額・相手のメモ）
- 家計簿の「支払い」のタブ：「返してもらう分」の一覧と合計、「返してもらった」を押すと精算の記録
- 計画（飲み会など）の精算は段階4（共有と一緒）

## 試験（作るとき、期待値は要件から手で作る）
- 4,000円を立替、自分の分 1,000円 → 今月の支出 1,000円・返してもらう分 3,000円
- 精算 3,000円 → 返してもらう分 0円・収入は増えない
- 経費 5,000円 → 支出 0円・返してもらう分 5,000円
- 立替の記録を消す・精算を消す・返金と重ねる・カード払いの立替・投資のカテゴリ
- 古いバックアップ（share が無い）を読んでも何も変わらない
