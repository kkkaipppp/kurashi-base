## 段階2 家計簿 立替と精算（自分用、2026-11-28。決定：金額は自分の分・総額を控える）
- 支出の入力に「立替（友達の分も払った）」：上の金額は払った総額のまま、自分の分を入れる。保存は amount＝自分の分・advanceGross＝総額（`lib/advance.ts`・`TxSheet.tsx`）。自分の分は1円以上・総額より少ない
- 立替の記録を開くと「返してもらった」：精算の記録（収入・収支に数えない・settles）を足す。保存の列の中で残りを確かめ直す。家計簿の「支払い」に「返してもらう分」と合計（`OwedAdvances.tsx`）
- 残高の目安：現金の立替は総額が出て、精算の額が入る。カードの立替は引き落とし待ちが総額増える。精算は立替の友達の分までしか数えない（`balance.ts`・`ledgerCore.ts` の settlement）
- 返金と立替は重ねない。固定費の支払いは立替にできない。立替を消すと精算も消える。返してもらった額より返してもらう分を減らせない。公開版では立替・精算の記録を直さない
- お金の計算の独立点検（kurashi-ledger）：中1 重複の候補を総額でも比べる・中2 指し先の無い／多すぎる／数え方の無い精算を残高に入れず点検に出す（settle-bad）・中3 精算を新しい記録として保存しない・低（固定費・削除の確認文・公開版）を直した
