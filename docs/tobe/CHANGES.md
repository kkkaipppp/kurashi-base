## 点検のあとの直し（kurashi-qa・kurashi-redteam、2026-11-27）
- 予定をカレンダーで直すと計画とのつながりが消えていた → 引き継ぐ（`lib/eventMerge.ts`）
- 「予定に入れる」の二重 → 保存の列の中で、同じ計画の予定があれば足さない（`addPlanEvent`・`planEventError`）
- 計画の日にちを変えると、つないだ1日の予定を同じ ID のまま移す（`setPlanDate`）
- 前のメニューにあった画面（やること・お金の記録・分類していない記録・レシートを見て入力・ウィジェット・バックアップ）に行けなくなっていた → メニューの下の一覧に戻した。使い方の文も合わせた
- 下のナビの初期から「やること」が外れていた → o31 の初期に戻した
- 旅行の計画で、旅行につないだ支出が数えられていなかった → 入れる（同じ記録は1回）
- 旅行を消すと計画の tripId が残っていた → 外す。IndexedDB の照合に計画とのつながりの数
- 公開版の組み立てに計画の検索の処理が残っていた → 環境の値を直接比べて消える形に
- 別のタブで計画が変わったら、日にち・予算・メモの欄を最新に作り直す
- 言葉：使ったお金→かかったお金、結ぶ→つなぐ、宿・移動→ホテル・航空券、メニュー→メニューに戻る
