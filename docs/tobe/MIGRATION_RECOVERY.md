# データの移行と復旧の手順（To-Be 段階1〜3。2026-11-27）

## 何が変わるか
- 記録に「計画」の一覧（`plans`）が足される。予定・やること・支出に、任意の `planId` が足される
- 形式の番号は **2 のまま**。今ある記録の中身・ID・金額は変えない
- 古い記録（計画の無いもの）は、読むときに `plans: []` を足すだけ（`lib/schema.ts` の `migrate`）。保存し直すまで端末の中の形は変わらない

## 確かめたこと（試験 `tests/tobe-plan.test.ts`）
- 計画の無い古い記録が、そのまま読める
- 形の崩れた計画（知らない種類・二重の ID・http/https でない URL）は読まず、黙って直さない
- バックアップの件数に「計画」が出る。追加の復元で計画が入る
- 計画を消しても、結んだ予定・やること・支出は残る（結び付けだけ外れる）

## 戻したいとき（ロールバック）
1. 先に「設定 → バックアップを書き出す」でファイルを作る（いつもの手順）
2. 前の版のアプリに戻した場合：前の版の読み込みは、知らない項目（`plans`・`planId`）を確かめずに残す作りになっている（コードを読んで確かめた。**前の版での実際の試験はしていない**）。計画の画面が無くなるだけで、ほかの記録は使える見込み
3. 計画を消してから戻したいときは、計画の画面で1件ずつ「この計画を削除」（結んだ記録は残る）

## 壊れたとき
- 今までと同じ：読めない記録は消さずに隔離し、ファイルに保存できる（`AppShell` の CorruptScreen）。自動で初期化しない
