# 製品のゴールと体験原則

**暮らしベースは、家計簿に小機能を足したアプリではない。** 予定・お金・日常のやることを一つのカレンダーで把握し、毎日の記録と判断を短時間で完結できる、暮らしのホーム画面である。

ユーザーが起動して3秒で答えを得る質問：
- 今日何がある？ やり忘れは？
- 今月あといくら使える？ 最近何にお金を使った？
- 今日/今週の予定と出費を同じ日付で見られる？
- 記録は最短の操作で追加/訂正できる？
- 期限が近い契約や固定費は何で、何をすればいい？

## 優先すべきジャーニー
1. **見る**：ホーム → 今日の予定と残り予算が一目で分かる
2. **記録する**：ホーム/カレンダーの＋ → 支出・収入・予定を自然に選択 → 入力 → 戻ると結果が反映
3. **振り返る**：月間レポート → 支出内訳/月比較 → 取引明細 → 修正
4. **管理する**：固定費 → 次の支払日 → 必要な時だけ記録/確認
5. **広げる**：タスク/資産/契約/勉強などへ必要なときに行く。頻度の低い領域が日常導線を圧迫しない

## 設計の優先度
1. データを失わない、誤計算しない
2. 主要画面の情報量を絞り、一度の操作で次の行動が明白
3. 伝わる自然な日本語と少ない入力
4. 必要ならいつでも戻れる、前画面の選択日やフィルタを維持
5. 実際に使えるものだけ「利用可能」と表示

## スコープ
MVPでは家計・予定・カレンダー・固定費・バックアップに加え、レポート/気づきと既存v2各領域への入口を整える。他の10領域は既存CRUDを守り、入り口/導線を改善。未実装の外部連携、AI、共有、OCR自動読取、PWA、iOSウィジェットは実装しない。
