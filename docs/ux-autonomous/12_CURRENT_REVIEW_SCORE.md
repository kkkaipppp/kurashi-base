# v2の暫定評価（旧UI参考との比較）

これらは企画・ソース読解に基づく**暫定の専門家スコア**で、画像を同じ機器で操作した比較試験/過去版の完全機能差分ではない。

| 指標 | Phase1の暫定値 | v2暫定値 | 改善後の目標 |
|---|---:|---:|---:|
| 機能範囲・入口 | 58 | 82 | 85 |
| 毎日使う導線 | 72 | 68 | 90 |
| 旧UIの分かりやすさの再現 | 62 | 64 | 90 |
| 日本語の一貫性 | 60 | 83 | 95 |
| データ安全性 | 65 | 66 | 95 |
| 検証・公開準備 | 55 | 63 | 90 |
| 総合（説明用） | **62/100** | **74/100** | **90/100（β公開目標）** |

※ 項目点と総合点は同じ算術平均ではない（安全性と日常導線の重みを重視した裁量評価）。v2は機能数と文言改善で進歩したが、旧UIの『予定とお金を一緒に直感的に使う』点では未達。**74点は再現率74%という意味ではない。**

## 更新方法
実装後に旧参考4画面と新画面を見比べ、A/B/Cシナリオを独立テスターが実行し、項目別点数と根拠を更新。見た目一致ではなくタスク成功率、操作回数、問題なし保存/復元、迷いの少なさで評価。
