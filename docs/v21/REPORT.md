## 開発結果
- **統合**：資料3巻・37ファイルの読了・分類・WBS/ロードマップへの統合（docs/v21/INTEGRATION.md）。機能の追加を止める決まり（Q24）は、平尾さんが中止。
- **実装（保存の形は変えていない。自分用が中心）**
  - CSV 取込（NEXT v21 CSV:C03〜C05）：引用符が閉じない CSV は始まった行を示して断る／エラーは最大10件を、エディタで見る実際の行番号で／足さなかった固定費は理由つき／ID 違いで日付・種類・金額が同じ記録の数を出す
  - ホーム：「今日のまとめ」と「確認したいこと」の二重表示を解消（まとめに出る分だけ除く。8件を超えた分・試験日も含めて確認）。予定の時間帯の補足は維持
  - グラフ：「数字で見る」に合計行と根拠の一文（投資を含む）
  - カレンダー：表示切替（予定とお金／予定／お金）を覚える。読み上げも見た目に合わせる。ICS の時刻の説明
  - 受入テスト：X01（旅行の二重計上なし）・X04（投資は生活費に入らない）・X05（画面どうしで同じ値）・X16（非表示でも集計に残る）
- **解消した矛盾**：ホームの二重表示、CSV の黙った欠落（引用符）、画面ごとの予算の数字（11-24 夜の分）。
- **Web／iOS**：コードは Web が master、iOS の部品（ウィジェット・カレンダー反映）は feat/ios-widget。今回の変更はどちらにも入っている。**iPhone への入れ直しは Mac に接続できず保留**（SSH がタイムアウト。Mac を起こして同じネットワークに戻れば再開できる）。
