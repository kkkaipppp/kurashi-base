## 承認が要るものの一覧（無断では進めない）

2. 大きなダウンロード（OCR の学習データ・評価用画像）
3. 有料契約（Apple Developer Program 年99USD、サーバー）
4. 利用者データの外部送信（今はなし）
5. 公開版（友人β）への機能の追加・push・デプロイ
