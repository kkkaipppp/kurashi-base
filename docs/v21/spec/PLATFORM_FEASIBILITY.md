# v13 Web/iOS能力とSonnet開発方針（設計承認済み・実装未検証）
現行資料にあるNext.js/Capacitor、WidgetBridge、EventKit書出し、日次バックアップを保護。以下は一般的技術判断で実機・最新提供条件未検証。
|機能|Web/PWA|iOS|検証|
|---|---|---|---|
|家計/予定/目標/予測/検索|共通TS|共通TS|同一入力の結果一致|
|保存|既存localStorage、IndexedDB比較|既存保存、SQLite比較|容量、消去、移行、復元|
|オフライン|Service Workerとキャッシュ条件|同梱資産と保存条件|初回/再起動/更新失敗|

|共有|ファイル選択/貼付を基本|Share Extension候補|iOS Safariの受信対応を仮定しない|
|通知|ホーム追加PWAのWeb Push等、配信基盤必要。任意時刻ローカル通知を保証しない|ローカル通知候補|権限、時差、休止、費用|
|カレンダー|ICS入出力候補|EventKit|外部ID、権限、往復重複|
|ウィジェット|アプリ内カード代替|既存WidgetKit|更新遅延、機密表示|
|生体認証|WebAuthnは認証であり保存暗号化と別|LocalAuthentication候補|ロック迂回、復元、脅威モデル|
|ショートカット/Siri|URL起動等限定|App Intents候補|署名、ロック、再実行|
|Watch|専用機能なし|別開発|費用、実機|
WebとiOSの保存領域は別。Safari/ホーム追加/Capacitor間の自動共有を前提にしない。ブラウザのデータ削除・容量圧迫・オリジン変更に備え外部バックアップと復元を必須検証。静的配信はHTTPS、サービスワーカー更新と旧データ互換を検証。無料ホスティングの利用規約・商用可否・上限、Apple署名/配布費用を確認するまで0円保証なし。外部送信・課金は別承認。
## Sonnet運用
Claude Sonnetを指すという仮定。開発モデルと製品内AIは別。小さな差分、関連仕様ID、対象ファイル、期待値、変更禁止範囲を渡す。計算・移行・権限・セキュリティは独立レビューと実機を必須。Opus等は必要時のみ別判断。モデル名や料金、利用枠は未確認。テスト合格だけで品質保証しない。

## v14 保存方針（承認済み、実装未検証）
Web IndexedDB、iOS SQLite第一候補。現行localStorageを直ちに置換しない。保存アダプタと共通計算、共通バックアップJSON/ZIP（版・件数・ハッシュ）、CSV/ICS可搬性。元画像とOCR結果を分離し保持選択。端末内世代バックアップと端末外保存を区別。移行は元データ保全→コピー→ID/金額/件数/参照/設定検証→切替→再起動/復元。切替後の新規書込もロールバック時に保護。中断・再実行・容量不足・複数タブを試験。暗号化は標準技術と鍵紛失時の説明、ライブラリ/ライセンス確認。10年試験は15件/日で約54750件、画像は別負荷。
