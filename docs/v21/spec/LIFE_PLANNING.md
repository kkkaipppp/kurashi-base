# v5 生活全体の計画・見直し（設計候補）
基準 d756cbc。v4の予定統合・目標構造化・サジェストは承認済み。以下の追加仕様は2026-11-24に設計承認済み。実装・実機検証は未済。

## 目標ロードマップと関係
目標→達成条件→マイルストーン→行動計画→共通予定→実績→見直し。親子関係と関連・依存関係を区別し、循環依存を拒否する。共有行動は既存予定IDを参照し、時間・金額・完了を重複計上しない。親目標の成果は子の完了率平均で代用しない。依存先が未完了なら理由を示し次の行動候補を提示。目標なし予定も維持。独立タスク台帳・ナビは作らない。

## 時間予算
週168時間を本人設定の睡眠・休息・仕事/通勤・生活・目標活動・余白に分ける。予定区間の重複は和集合で計算、カテゴリ競合は確認候補。終日・期限のみ・日付未定は時間を推定せず未配分扱い。予定と実績を区別し、実績未入力は不明。週境界・日跨ぎ・タイムゾーンを考慮。空白を自由時間と断定せず、本人指定の利用可能枠と余白を使う。睡眠・休息を削る提案はしない。金銭予算は既存共通計算を参照し別台帳を作らない。

## 計画再調整
未完了予定を自動繰越しない。延期・縮小・中止・維持・再配置・目標休止の候補を出す。期限・依存関係・本人の優先順位・時間予算・金銭予算を確認。情報不足は不明と表示。変更前後の日時・費用・影響をプレビューし、承認された変更だけを適用。繰り返しの単発/以後を区別、過去実績は保持。変更の取り消しと生成キーによる冪等性を確保。

## 週次レビュー
振り返り画面に任意の週次タブを追加（下部ナビ維持）。支出対予算、行動実績対計画、完了管理対象の完了率、時間余白の推計、成果指標を別々に表示。対象期間・分母・欠測・計算根拠を明示。提案は最大3件を初期案とし、理由・選択肢・却下/保留を提供。通知は任意。本人の承認なしに予定・家計・目標を変更しない。

## 受入条件
- 親子/依存循環拒否、共有予定の二重計上なし、目標解除後も過去実績保持。
- 重複区間、日跨ぎ、週境界、未定予定、実績欠測、予算超過を検証。
- 提案の拒否・取消・再実行・部分承認で意図しない変更や増殖なし。
- 週次レビューの分母ゼロ、未測定、未分類、予定と実績の区別を検証。
- 無料・端末内・オフラインで基本動作。現行デザイン、5ナビ、本人版/公開版分離を維持。
- 実機で目標作成→予定承認→実績→週次見直し→取消の往復を検証。未実施はNOT_RUN。
