# v18 地図・ナビ連携（設計承認済み、全試験NOT_RUN）
根拠: d756cbc app/src/lib/externalLinks.ts の mapsDirections は Google Maps URL api=1、destination、travelmode（walking/driving/transit）、originなし。mapsSearchあり。EventSheet/tripsから参照。実機未検証。
M01 既存リンク維持。予定詳細から既定地図へ1タップ。未設定・空場所・起動失敗時は住所コピー/ブラウザ検索。外部に渡す項目を説明。
M02 Google/Appleを選択、既定値は利用者が変更。AppleのURL・OS/ブラウザ・交通手段対応を実機検証、未対応時はGoogle/コピー。自動起動なし。
M03 場所は名称・住所・座標・元URLを任意保持。URLは許可ホストとhttpsを検証、短縮URLは自動解決せず手動確認。施設名だけの場合は曖昧さを明示。外部検索結果の自動取得なし。
M04 到着予定から移動時間と余裕を引く。移動時間は手入力/過去の利用者確認値、取得日時と推計区分を表示。未入力は不明、0分にしない。日跨ぎ/時差対応。通知は明示承認。
M05 徒歩/電車/車を選択、既定値は記憶。地図側で変更可能。出発地は現在地（地図側）/指定場所/前予定の場所。位置権限を必須にしない。
M06 移動は共通予定と関連付け、重複生成防止、前後予定の変更で再計算候補、実績を捏造しない。移動不足は警告のみ。予定削除時の関連処理を確認。
M07 よく行く場所を任意保存、名称と住所を編集・削除、履歴と分離。自宅等は外部送信・ウィジェット表示を明示選択。
M08 旅行の訪問順・区間ごとの経路・予定費用。全旅程を勝手に外部送信しない。順序最適化/リアルタイム運行は初期範囲外。
M09 交通費は予定額と実績を区別し共通家計IDで関連付け。カード引落等の二重計上防止。未登録額は不明。
M10 無料URL連携優先。APIキー・有料経路API・常時位置取得・埋込地図・自動運賃取得は必須にしない。外部地図の規約・通信・オフライン制約を説明。
受入: 各Mの正常/異常/権限拒否/未対応/オフライン/日本語URL/日跨ぎ/時差/予定変更/重複/費用集計/プライバシーを検証。Web Safari/PC/iOS別、実機で外部起動と復帰、入力保持。全NOT_RUN。
使い方: 予定の場所に名称・住所を登録→行き方を調べる→地図で時間を確認→戻って移動時間と余裕を入力→必要なら出発予定を追加。設定で既定地図・移動手段を変更。地図が開かない場合は住所をコピー。外部地図には選択した場所等が渡る。実装画面に合わせて更新。
