# v20 カレンダー詳細設計（設計承認済み・実装未検証）
根拠: d756cbc app/src/app/calendar/page.tsx を確認。月表示、予定名最大2件/+n、予定とお金/予定/お金、日別実績、今日、選択日追加、祝日、期限マーカー、個人版固定費次回支払予定あり。週日表示なし。以下は提案。
C01 月セルは日付・予定名最大2件/+n・金額・期限を優先。点表示は選択肢。実績/予定の符号とラベルを区別。選択日詳細へ。既存5ナビ・色意味維持。
C02 予定/タスク/習慣/目標行動を共通予定に。開始終了・期限・完了・繰返し独立、日付未定一覧、期限変更は明示。既存ID・参照維持。
C03 月/週/日/一覧、初期月、選択日・フィルタ・スクロール保持、今日、週開始設定、月跨ぎ・終日・複数日。年は概要候補。
C04 選択日+、タイトルのみ可、任意時刻/期限/場所/目標、下書き、自然文候補確認。長押しは補助のみ。
C05 編集/複製/延期/完了/取消。複製は新ID、実績を複製しない。ドラッグは試験後、ボタン代替。期限を勝手に変更しない。
C06 series/occurrence ID、今回/今後/全件、月末・閏日・例外・終了・通知取消。固定費は共通ledgerの予定と実績を照合、完了だけで支出生成しない。
C07 日別収入支出実績と支払予定/予算を別表示。返金・振替・カード精算・投資は共通計算。購入日/決済日を区別。予定実績リンク、二重計上禁止。未記録≠0。
C08 目標行動は既存予定参照、達成条件と実施実績別。提案は承認後、共有行動一件、変更/取消可能。
C09 場所・外部地図・移動時間・余裕・出発逆算、登録値と推計を区別。前後予定の衝突警告、地図API必須にしない。
C10 空き時間は登録済み予定と本人の利用可能時間/休息/移動から候補化。空白≠自由時間。衝突は警告、無断登録なし。
C11 外部カレンダーは既存exportを維持、importは別権限・外部ID・ループ防止・競合確認・取消。WebはICS候補、iOS EventKitは実機検証。権限拒否でも基本利用可。
C12 表示項目・週開始・色・既定表示、非表示は削除でない。色以外の識別、フィルタと読み上げ一致。版別承認。
C13 通知は明示設定、静穏時間、重複抑止、変更/削除/完了時取消、時差・権限拒否・Web制約。ロック画面の機密情報保護。
C14 年間概要/旅行/生活イベントは共通予定と家計参照。期間跨ぎ・日付未定・過去の履歴維持。テンプレートは実績を複製しない。
C15 320/375/390/430幅、44pt目標、VoiceOver、文字拡大、片手、キーボード、オフライン、10年データ、日付境界/時差/DST/閏年、回帰・版別試験。
使い方: カレンダー→日付→追加→タイトルと任意日時/期限→保存。完了・延期・繰返し変更の範囲・取消を説明。表示切替、支払予定と実績の違い、地図、外部連携の権限と代替を説明。実装画面と照合。
