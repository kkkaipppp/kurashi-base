## 横断シナリオ
1. 飲み会予定5000円→実績3000円→残予定2000円（部分払いの場合）→完了確定→未消化分解除→返金→取消。予算・旅行・履歴の合計一致。
2. 資格目標→提案選択→予定登録→繰返し一回完了→実績未入力→週次見直し→部分承認→取消。成果を捏造しない。
3. 機内オフラインで支出入力→保存中強制終了→再起動→重複なし→バックアップ→別端末復元。Web/iOS別検証。
4. 7日間未利用→通知拒否→今日から再開→ホーム非表示→再表示。データ保持。
5. 旧版データ→移行→再実行→復元→本人版/友人版の提供機能確認。公開変更は別承認。
