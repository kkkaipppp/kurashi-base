# v15 利用者支援・失敗からの復帰（設計承認済み）
H01 初回：目的選択は任意、スキップ可能、サンプルは実データと分離。最初の支出/予定を登録できるまで検証。
H02 操作説明：各主要機能に目的、前提、入口、手順、結果、取消、制約、Web/iOS差を記載。画面の実装と同じ版で更新。未実装は説明を公開しない。
H03 CSV：出力元の公式手順を実サンプルで確認、ファイル選択→列対応→重複/エラー確認→確定→履歴/取消。出力有料条件は明記。汎用テンプレートと匿名例を提供。
H04 エラー：何が起きたか、保存されたか、次の操作を明示。入力保持、再試行、取消。原因不明を断定しない。
H05 空状態：未入力とゼロを区別。最初の操作への導線。架空の実績を表示しない。
H06 復帰：長期未使用でも連続利用を強制せず、未整理/期限/バックアップを任意確認。過去の空白を自動補完しない。
H07 信頼：予算・残高・予測の定義と計算根拠、データ不足、更新日時を表示。提案の根拠と拒否を提供。
H08 権限・端末差：拒否時の代替、設定への案内、実際の能力に応じた表示。Web通知やウィジェットを誤案内しない。
H09 データ救済：端末内と端末外を区別。復元前プレビュー、現データ保護、別端末で復元確認。書出し成功と外部保存確認を区別。
H10 継続保守：検索可能なヘルプ、版別更新履歴、問い合わせ用の個人情報を除いた診断情報を本人選択で出力。問い合わせ窓口未設置なら明示。
## 機能別ガイド必須項目
家計：追加→修正→返金/振替の意味。予定：日時/期限/完了/繰返し。目標：達成条件→提案確認→予定→見直し。旅行：関連付けと二重計上防止。CSV：H03。OCR：候補修正と元画像の扱い。ウィジェット：OS別追加手順と更新制約。バックアップ：保存先選択→検証→復元。設定：分類/ホーム/通知/権限。各ガイドは実装後に画面と照合。
## 受入
H01–H10すべてNOT_RUN。初見利用者が説明なしで主要操作、必要時のみヘルプで解決できるか観察。誤操作・権限拒否・容量不足・復元・長期離脱を試験。成功表示は実際の確定後。説明と実画面の不一致は修正。既存の良い導線を維持。無料・端末内保存を維持。
