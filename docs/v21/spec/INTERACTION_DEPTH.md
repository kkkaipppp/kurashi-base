# v12 操作・設定・通知・ウィジェット（設計承認済み・実装未検証）
基準 d756cbc。v11資料を根拠にした設計。現行画面の全数実測なし。
## 操作
支出は＋→金額・分類→保存、最近の記録複製は日付・金額を確認し新ID。予定は＋→内容・任意日時→保存、完了は一覧で操作し取消可能。延期は期限と開始日を独立保持。検索から戻ると条件・位置保持。保存ボタンはキーボードと安全領域を考慮。入力途中の戻る・二重押下・保存失敗・再開を試験。2タップは入口まで、5秒は慣れた利用者の単純支出の仮説。初見と反復、修正込み時間を別測定。
## 設定
従来4分類案を6分類候補に変更：ホーム・見た目／お金／予定／通知／他のアプリとつなぐ／データ・プライバシー。既存アンカー・設定値を保持。各画面から関連設定へ直接遷移、戻ると元画面保持。機能がない版では設定も隠す。設定検索は項目増加時に検討。初期値・変更結果・初期化範囲を明示。全削除は独立確認。設定変更で記録を消さない。
## 通知
予定開始・支払期限は本人が設定した場合のみ。予算・目標・週次・再開は初期オフ候補。休止時間、まとめ、重複抑制、金額非表示。通知IDは予定発生回等に関連、編集・削除・取消・時差で再計算。OS拒否時はアプリ内確認のみ。緊急性を捏造しない。ロック画面は機密情報を初期非表示候補。通知の実行時刻はOS依存、保証しない。
## ウィジェット
既存WidgetBridge/WidgetSyncを再利用。家計、予定、目標、クイック入力、統合の5候補。表示は共通集計・同一日付基準、最終更新と古い情報、欠測、非表示設定を反映。クイック入力はまずdeep link、直接操作はApp Intents等の実機検証後。読取は共有またはアプリ起動、ロック時の機密操作を検証。Web代替はホーム画面。更新要求と実際の描画を区別。
## 利用者別・視覚
初回プリセットと既存並替えを利用、初心者/上級者の固定モードは作らない。詳細を段階表示し本人が開いた状態を必要に応じ保持。色だけで区別しない、タップ領域44pt相当を目標、文字拡大で切れない、動き軽減、フォーカス順、左手右手・キーボード試験。既存ブランドと5ナビを維持。
