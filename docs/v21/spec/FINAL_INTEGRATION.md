## シナジーの実装単位
家計×カレンダー=支払予定と実績、家計×目標=予算と貯蓄計画、予定×目標=行動時間、予定×地図=出発逆算、旅行×家計=予算実績、旅行×地図×予定=旅程、契約×家計×予定=更新/解約期限、OCR×家計×検索=入力削減、資産×家計×予測=将来比較、履歴×テンプレート=計画再利用。各組合せは独立台帳を増やさず既存IDを参照。共通データ基盤は単一巨大テーブルを意味しない。
## 共通契約
原本・予定・候補・派生集計を区別。共通ledger/予定展開/提案/検索/保存インターフェースを画面から分離。金額は整数最小通貨単位、通貨別、換算根拠保持。集計は期間・版・フィルタ・通貨・計算定義を明示。関連変更は原子的に確定し再実行安全。設定6分類=ホーム・見た目／お金／予定／通知／他のアプリとつなぐ／データ・プライバシー。5ナビ=ホーム、カレンダー、中央＋、振り返り、メニュー。旧資料のR表記・設定4分類・承認待ちは履歴として扱う。
## 試験
X01–X25を各IDの期待値で試験し、関連するQ/D/C/G/M/P等の受入も同時実行。Cの重複は CSV:C01–10 と CAL:C01–15 の名前空間で識別。B/V等もファイル名で名前空間化。重大計算・消失・漏洩は即停止。全NOT_RUN。
