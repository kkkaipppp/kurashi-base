# v13 意思決定・経験再利用（設計承認済み・実装未検証）
既存5ナビ、無料、端末内、共通台帳を維持。独立したAI画面は作らない。
## 判断支援
購入・契約・旅行・引越・転職の比較は共通シナリオ。基準日時、対象期間、入力根拠、確定/見込み/不明、初期費用、継続費用、終了費用、時間、本人の優先条件を保持。比較案は下書きで台帳に計上しない。承認後のみ予定支出等へ関連付け。予算残と現金残高を分離し、予定支出が既に控除済みなら再控除しない。税・手数料・為替・収入の欠測を明示。推奨は本人条件に対する比較結果であり購入可否の断定ではない。
## 未来予測
確定・予定・仮定を区別した時系列。支払日基準の現金予測と利用日基準の予算を別表示。最小残高と不足日を示す。基準残高が不明なら算出不可。楽観/標準/慎重は本人が入力した仮定であり確率ではない。実績照合・取消・部分払い・返金で再計算。時間は予定の区間和、休息・本人指定の余裕を除き、未登録時間を自由時間と断定しない。
## 経験の再利用
過去の旅行や資格計画から、費用内訳・所要時間・準備項目を選んで新規計画の候補にする。元記録のIDと期間を参照、実績は複製しない。人数・日数・通貨・物価・条件の差を明示。少数事例は参考値。検索は日付・金額・分類・関連イベント・文字列、結果から元記録へ。年次振り返りは欠測と集計範囲を明示。
## 画面
お金の詳細に「買ったらいくら残る？」、旅行詳細に「前の旅行を参考にする」、目標詳細に「計画を見直す」。比較はメニューからも到達可能だが独立ナビ追加なし。提案は理由・前提・変更点・取消を表示。外部価格や市場情報を取得したふりをしない。
## 受入（全NOT_RUN）
V01 予算に予定費用控除済み/未控除の両方で二重控除なし。V02 カード利用と引落で現金・予算別計算。V03 基準残高欠測・外貨・返金・部分払い。V04 比較案の保存/破棄で台帳不変、承認再実行で重複なし。V05 旅行テンプレート複製で実績不変。V06 休息と重複予定を考慮、欠測を明示。V07 予測根拠と元記録へ遷移、変更時再計算。V08 オフラインで比較と検索、外部APIなし。
