# v21 Web / iOS 提供差分（目標、実機未検証）
|機能|Web/PWA|iOS|条件・代替|
|---|---|---|---|
|家計/収支/予定/目標/資産/旅行/契約/検索/予測|共通TS|共通TS|同一合成入力の結果一致、版別機能制限|
|CSV/バックアップ|共通形式|共通形式|復元前プレビュー、外部保存|
|保存|現行localStorage→IndexedDB候補|現行保存→SQLite候補|別領域、自動同期なし、移行別承認|
|オフライン|初回取得とキャッシュ条件|同梱資産と保存条件|実機で再起動・更新試験|
|OCR|WASM候補|Vision候補|精度/速度/ライセンス、手入力代替|
|外部共有|ファイル選択/貼付|Share Extension候補|権限、未対応時代替|
|カレンダー|ICS候補|既存EventKit出力、取込候補|外部ID/ループ防止|
|地図|URL連携|URL連携|Apple/Google、時間は手入力、外部送信明示|
|通知|アプリ内、Web Pushは基盤必要|ローカル通知候補|任意時刻保証なし、拒否時代替|
|ウィジェット|アプリ内カード|既存WidgetKit|更新遅延/秘匿/実機|
|ショートカット/Siri|URL等限定|App Intents候補|署名/権限/再実行試験|
|生体認証|WebAuthn候補、暗号化とは別|LocalAuthentication候補|脅威モデル、回復|
|Watch|対象外|将来別開発|費用/実機|
|PC|ブラウザ|対象外|レスポンシブ|
|配布|静的無料枠候補|個人署名制約、正式配布費用|規約/価格再確認、別承認|
本人版・友人版は別軸。既存の版制限を解除しない。Safari/PWA/Capacitor間のデータ共有を仮定しない。ユーザー向けガイドは環境別に出し分け、未提供機能は表示しない。詳細は PLATFORM_FEASIBILITY / FREE_OPERATIONS / MAP_NAVIGATION。全NOT_RUN。
