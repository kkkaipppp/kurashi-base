# v19 収支グラフ改善（設計承認済み・全試験NOT_RUN）
根拠: d756cbc の report/page.tsx, PeriodReport.tsx, TrendChart.tsx, report.ts を確認。週・年はpersonal限定、月は共通。週年は棒と累計線の二軸、数値表あり。月は円・週別支出・同日比較・単純ペース予測。既存の色意味・画面・版境界を維持。以下は追加設計。
G01 判断目的: 振り返り上部に収入・支出・差額、比較期間、記録範囲。残高/純資産/予算残/累計収支は別指標。計算根拠を表示。
G02 共通ledgerから集計。生活費、投資、振替、返金、カード精算、固定費予定と実績、外貨を区別。未対応の取引は確認待ち。ホーム・明細・CSVと照合。過去の分類変更/予算変更の適用期間を保持。負の分類合計を円グラフに無理に描かない。
G03 棒=期間別収入支出、線=収支累計/残高/資産（別指標）、横棒=分類比較、円=非負の構成比のみ、差分棒=増減寄与。二軸は既存維持し単独表示を追加候補。ゼロ基準、負値、桁、凡例、単位、色以外の識別、数値表、VoiceOver。サンプル配色は正式変更ではない。
G04 日週月年任意期間を実データで集計、週開始・月末・閏年・時差、未来は実績なし。週年を月額換算しない。期間移動・今日に戻る、選択状態保持。個人版/公開版は別承認。
G05 前期/前年/予算/平均は同じ範囲・定義・通貨で比較。途中月は同日、短い月は共通日数か差を明記。比較元ゼロは率なし、欠測は不明。差分寄与合計=総差額。理由を推測しない。
G06 分類/店舗/支払方法/固定変動/生活投資の絞り込み、その他展開、未分類表示。フィルタ適用範囲を明示。比率分母・丸め・返金を明示。
G07 月末予測=記録済み実績+未計上の確定予定+重複しない変動費推計。固定費照合・部分支払・予定変更を考慮。根拠/更新日/不足情報/範囲を表示。実績は実線、予測は破線。残高予測は初期残高と決済日が必要。不明なら出さない。過去の予測を実績にしない。
G08 グラフ選択から同じ条件の明細へ、戻ると期間・フィルタ・スクロール復元。その他は複数分類、集計と明細の一致。タップ代替の表。
G09 グラフ表示順・非表示・既定期間を任意設定。非表示は削除でない。初期は概要/推移/内訳/比較、予測は条件が揃う場合。既存5ナビ維持。
G10 変化の事実と提案を区別。上位寄与、臨時費、予算差を根拠付きで最大3件候補。記録不足時は断定しない。予算や分類を無断変更しない。
使い方: 振り返り→期間選択→収支/推移/内訳→比較対象選択→グラフまたは表から明細→必要なら予測の根拠確認。表示設定で不要なグラフを隠す。実装画面と一致させる。
受入 G01–10: 既存回帰、ホーム/明細/CSV一致、収入ゼロ/赤字/返金/振替/投資/カード/固定費部分照合、月途中/短月/閏年/時差、欠測/未来/比較元ゼロ、負値/巨大値/小画面/VoiceOver、フィルタ復帰、予測二重計上なし、版別ビルド、10年データ性能。全NOT_RUN。Phase1既存計算・表示・説明、Phase3共通ledger連携、Phase4予測・比較。新規ライブラリは必要性確認後。
