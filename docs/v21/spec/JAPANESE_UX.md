## 原則
日常語、行動を表すボタン、具体的な対象、短い見出しと必要時の補足。専門用語は必要な場合のみ説明付きで残す。金融・削除・復元・権限の意味を省略しない。敬体を基本に見出しは名詞。既存の自然な名称は維持。予定とタスクの統合は既承認、名称変更だけで完了扱いにしない。
