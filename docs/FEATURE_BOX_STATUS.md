## データの保護
- 保存形式を v1 → v2 にした。v1 のデータは読み込むときに自動で移行し、取引・予定・固定費・予算・表示設定は**1件も変えない**（単体テストで確認）。読み込むだけでは保存領域を書き換えず、次に保存したときに v2 になる。
- v1 のバックアップファイルからも復元できる。
- 予定の繰り返しは「項目を足す」形にしたので、v1 の予定は今までどおり（繰り返しなし）として扱われる。
