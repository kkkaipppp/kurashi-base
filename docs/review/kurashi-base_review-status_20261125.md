## 3. 守っていること（安全）
- 保存の形：schemaVersion 2・保存キー `kurashi-base:data:v1` は変えない。追加した項目は、すべて任意（古いデータはそのまま読める。`tests/` に検査あり）。
- 公開版に自分用の機能を出さない：`FEATURE_EDITIONS` と、各ファイルの中での版の比較（`PERSONAL_BUILD`）。公開用に作り直した出力を検索して確認（部品の文字列が入っていて画面には出ないもの：買い物の判断・未整理の記録・生活の変化の「この版では、まだ使えません」の画面）。
