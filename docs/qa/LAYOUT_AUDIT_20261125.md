# 画面幅の点検（2026-11-25 夜。N03・N15 の「4画面幅・文字の拡大」）

## 調べ方
- 本番と同じ組み立て（`next build` → `next start`、localhost:3212）を、アプリ内ブラウザで開いた。作り物のデータを入れた（とても長い店名・予定名・固定費名、大きい金額 9,876万円・予算 9,999万円、40件ほど）。終わったら消した。
- 全28画面を、幅 320・375・390・768・1280px と、195px（390px の iPhone で文字を200%にしたときに近い狭さの代わり）の iframe で開き、`scrollWidth > clientWidth`（横にはみ出し）を機械で調べた。はみ出した要素は、いちばん外側のものを記録した。
- 公開版と自分用の版の両方で調べた。

## 結果（公開版）
| 幅 | はみ出し | 直したこと |
|---|---|---|
| 320・375・390 | ホームの「次の固定費」（長い名前と大きい金額が並ぶ） | 名前は折り返し、金額は縮めない（`app/page.tsx`） |
| 768・1280 | なし | — |
| 195（文字200%相当） | ホーム（上と同じ）・振り返りの「支出の内訳」（円グラフと一覧が横並び）・買い物の判断の表 | 内訳は狭いと円グラフの下に一覧を並べる（`report/page.tsx`）。表は表の中だけ横に動かせる（`decide/page.tsx`） |

## 結果（自分用の版）
| 幅 | はみ出し | 直したこと |
|---|---|---|
| 320 | ホーム・旅行・生活の変化（空白のない長い名前が折り返さない） | 画面全体に `overflow-wrap: break-word`（`globals.css`）。空白のない名前・URL も幅で折り返す |
| 375・390・768・1280 | なし | — |
| 195（文字200%相当） | 上と同じ＋振り返り・履歴・タスク | 同上 |

## 直したあと（両方の版）
- 320・375・390・768・1280：全28画面で、はみ出しなし（文字の位置まで調べた）
- 195：タスクの「今日まで」の小さな印が 4px だけ出る（読むのに困らない）。ほかははみ出しなし

## 未確認
- iPhone の「文字を大きく」（アクセシビリティ）を実際に 200% にしたときの見え方：DEVICE_PENDING（195px の幅は代わりの目安）
- VoiceOver での読み上げの順番と、ボタンの名前：DEVICE_PENDING
