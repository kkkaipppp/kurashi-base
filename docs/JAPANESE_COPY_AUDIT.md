対象：既存の全画面（ホーム・カレンダー・取引履歴・設定・固定費・画像取込・入力シート・確認ダイアログ・トースト・エラー文・保存データの異常画面）と、今回追加した全画面。
方法：画面のソースから表示文字列を全件抜き出し（`grep`）、`docs/autonomous_pack/reference/07_JAPANESE_UI_COPY_GUIDE.md` の原則で見直した。データのキーや内部の識別子は変更していない。旧アプリの確定文言は提供されていないため、下の文言は**旧版と同じだとは言えない**（自然さと統一を優先した提案）。

- 用語の統一：支出／収入／予定／タスク／固定費／取引履歴／画像から取り込む／保存／キャンセル／削除

- エラーは「保存できませんでした。」から始め、できる対処を書く。同じ言葉が2回続かないようにする

# 第2回：選択肢の並び・欄の名前・構造（2026-11-21、ユーザーの指摘を受けて）

ユーザーの指摘：「日本語と構造化がへんなのがある」「選択肢が並列じゃないものがある」「NISAの枠がへん」。

## ルール（今後もこれに合わせる）
1. **選択肢は同じ種類・同じ粒度・同じ形の言葉で並べる。** 種類の違うもの（測ったもの／できごと）は、グループに分ける
2. **欄の名前**：物には「名前」、タスク・目標は「内容」、メモ・予定は「タイトル」
3. **チェック欄は短い名詞**：完了／達成／上に固定／有効／終日
4. **任意の欄**は、ラベルに「（任意）」と書かず、横に小さく「任意」の印を付ける
5. **メニューのグループは中身の種類で分ける。** 「準備中」は状態なので、グループにはせず各項目の印にする
6. **画面名は短い名詞**（「NISAの枠」→「NISA」）。正式名は説明文に書く
