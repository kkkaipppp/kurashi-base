# 日本語UI文言の修正指示

## 目的
現行アプリ内の不自然な日本語・直訳調・意味不明な表現・文字化け・不統一な用語を修正し、自然な日本語の生活管理アプリにする。**データベース、配色、配置、レイアウトの変更は対象外**。

## 原則
- 現行アプリの全画面、ダイアログ、入力欄、空状態、通知、エラー、設定、アクセシビリティラベルを棚卸しする。
- 旧アプリの実画面・確定文言が提供されている場合はその文言を優先する。提供されていない文言は自然な日本語で提案し、旧版と同一と断言しない。
- UI表示文字列だけを修正し、データキーや内部識別子、既存の保存済みデータを壊さない。
- 用語は統一する。「支出」「収入」「予定」「タスク」「固定費」「取引履歴」「画像から取り込む」「保存」「キャンセル」「削除」。
- 空状態は状況と次の操作が分かる文言にする。例「まだ予定がありません」「予定を追加」。
- 確認ダイアログは対象と結果を明示。例「この支出を削除しますか？」「削除すると元に戻せません」。
- エラーは原因を断定せず、可能な対処を示す。例「保存できませんでした。もう一度お試しください」。
- OCRや外部連携など未実装の機能は「利用可能」と誤認させない。
- 数字・日付・金額は日本語の利用文脈に沿って表示し、年月日や曜日表記を揃える。

## 文言例（旧版の確定文言ではない）
|用途|推奨表示|
|---|---|
|ホーム|ホーム|
|カレンダー|カレンダー|
|支出追加|支出を追加|
|収入追加|収入を追加|
|予定追加|予定を追加|
|画像取込|画像から取り込む|
|取込結果|読み取り結果を確認|

|月の残額|今月の残り|
|保存完了|保存しました|
|未実装|準備中|

## 検証
1. 各画面で日本語が文字化け・欠落・折り返し破綻していないことを確認。
2. 全主要操作で表示文言が実際の動作と一致することを確認。
3. 既存機能の登録・編集・削除・保存・復元を回帰確認。
4. `docs/JAPANESE_COPY_AUDIT.md` に修正前後、対象画面、未解決事項を記録。
