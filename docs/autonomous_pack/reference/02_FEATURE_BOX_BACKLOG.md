# 機能の箱バックログ

「箱」とは、ユーザーが機能の存在と用途を理解し、開けて、空状態/説明/主要アクションを確認できる状態。外部連携や計算処理が未実装なら、**利用可能と誤認させない**。

|優先|領域|最低限の体験|初回到達目標|
|---|---|---|---|
|P0|タスク管理|タスク一覧・追加・編集・完了・期限・未完了の表示|箱＋基本操作|
|P0|資産管理|資産サマリー・保有項目・評価額の手動登録入口|箱＋手入力|
|P0|契約管理|契約一覧・更新日・支払額・解約/更新確認入口|箱＋基本操作|
|P0|生活記録|日付別の記録一覧・メモ追加・振り返り入口|箱＋基本操作|
|P0|健康管理|健康記録・日付・数値/メモ入力入口|箱＋手入力|
|P0|目標管理|目標一覧・期限・進捗の登録入口|箱＋基本操作|
|P0|共有管理|共有対象・招待・権限の概念を確認できる入口|箱のみ（招待送信不可）|
|P0|AI生活支援|AIへの相談・提案履歴・権限説明の入口|箱のみ（生成AI未接続）|
|P0|外部サービス連携|連携先一覧・接続状態・連携可否の説明入口|箱のみ（接続不可）|
|P0|生活書類管理|書類一覧・分類・期限・追加入口|箱＋ローカル仮登録|
|P1|OCR取込|画像→候補抽出→修正→確定の操作フロー|箱＋抽出方式の試作|
|P1|通知/ショートカット|決済入力の受け口・設定導線・制約表示|箱＋実現可能性検証|
|P1|ウィジェット|今日の予定と支出を表示する想定内容・状態の確認|アプリ内プレビューのみ|

|P1|繰り返し予定|繰り返し設定と予定一覧での状態確認|箱＋可能なら基本操作|
|P1|返金・振替・分割|家計取引の種別入口と注意書き|箱優先|
|P1|毎週固定費|周期選択・次回予定の概念|箱＋可能なら基本操作|
|P2|同期・アカウント|ログイン/同期/共有の機能案内と状態|箱のみ（未接続明示）|

## P0の完了基準
- 既存の主要6画面と家計/予定操作を壊さない
- 10領域それぞれに到達でき、名称・目的・空状態・次の操作が分かる
- 基本操作が可能と指定した箱は最低限の登録・一覧・編集・削除/完了が実際に動く
- 未接続の箱は「準備中」「未接続」と明示し、成功したふりをしない
- 画面構成・配色・配置は現行アプリのデザインルールに従いClaudeが判断する
