Claude Codeへの実装指示：暮らしベース「機能の箱」拡張

現在の作業ディレクトリにある暮らしベース Phase 1 を継続開発してください。添付ZIPを展開してREADMEと01〜04を読んでください。

目的は、家計・予定を中心とする現行アプリを壊さず、生活統合アプリの12領域に向けて不足する機能の「箱」を揃えることです。今回は精密な完成版ではなく、次回からユーザーとブラッシュアップできる、実際に触れる骨格を作ります。

【最重要】データベース・スキーマ・保存方式・配色・配置・UIの具体的レイアウトは指示しません。あなたが保持する現行の設計・仕様・デザインを正本とし、それに自然に統合してください。既存コードの全面作り直しは禁止です。

進め方：
1. 現行コードと既存資料を確認し、01の差分評価が実際のコードと一致するか検証。異なる場合はコードの事実を優先。
2. 02のP0から着手。10領域の機能入口・空状態・説明・主要アクションを揃える。基本操作指定の領域は実際に動く最小限のCRUDを作る。
3. 外部サービス、共有、AI、iOS機能は未接続のままでもよいが、できるふりはしない。P1は余裕があれば着手。
4. 現行の家計・予定・固定費・画像取込・バックアップの回帰テストを実施し、`npm run check` を通す。新しい箱の基本テストも追加。
5. `docs/FEATURE_BOX_STATUS.md` に機能別の実装状態、PASS/FAIL/NOT_RUN、残課題を記載。

ユーザーへの質問は、破壊的変更・課金・外部データ送信・認証の有効化など重要判断が必要な場合に限定してください。その他は合理的に判断して前進してください。完成した箱を見て次に改善するため、未実装部分は明確に残してください。

最終報告は「追加した箱」「実際に動く操作」「まだ動かないもの」「既存機能の回帰結果」「次に一緒に磨く候補」の5点を簡潔に示してください。
