# 再現性の範囲

このパックは旧製品の「機能領域の箱」と日本語の自然さを揃えるためのもの。旧版のソースコード、最新画面キャプチャ、確定文言一覧を完全照合したものではない。

## このパックで狙えること
- 12領域に向けた機能入口の網羅
- 基本操作が指定された領域の最低限の動作
- 既存の画面設計を維持した日本語文言の修正

## これだけでは保証できないこと
- 旧版の画面・文言・操作の完全一致
- OCR精度、iOSウィジェット、通知自動取得の実機動作
- 旧版の全例外処理や業務ルールの一致

旧版に近づけるためには、旧版の最新スクリーンショットと実際の操作シナリオを別途比較する。推測で「完全再現」と報告しない。
