# 暮らしベース 自律開発 最終実行パック

## 使い方
1. **現在のPhase 1プロジェクトのルート**に、このZIPの内容を `docs/autonomous_pack/` として展開する（`app/` のコードを上書きしない）。
2. Claude Codeを現在のプロジェクトルートで開き、`01_COPY_TO_CLAUDE.txt` を貼り付ける。ZIPの展開場所が違う場合はパスだけ調整。
3. Claudeが現在のコードと資料を検証してから実装を始める。完了後はレポートを確認する。

## このパックの役割
既存の動作する家計・予定アプリを維持しつつ、生活管理12領域の不足する箱を増設し、日本語の表示を整える。新規プロジェクトの再作成ではない。

## 大事な境界
- DB、保存方式、スキーマ、配色、配置、レイアウトを本パックから指定しない。Claude側の現行設計を正とする。
- 旧アプリとの画面・機能の完全一致を保証しない。実画面の確定文言がない場合は自然な日本語を採用。
- 外部連携、AI、共有、同期、通知などは実際の接続がない限り「準備中」と明示する。
- 自律実行はClaude Code側の権限・セッション・実行環境に依存。無断の外部公開、課金、秘密情報送信、破壊的操作は禁止。
