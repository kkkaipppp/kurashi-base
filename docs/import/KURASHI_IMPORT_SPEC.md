# くらしベースに取り込む CSV の形（マネーフォワード ME の整理用）

作成：2026-11-24（目利き商店のチャットからの依頼）。
くらしベース側は、この CSV を「バックアップから復元 → 今のデータに追加する」で読めるファイル（JSON）に変える。
変換のスクリプトは、くらしベースのチャットが作って動かす。目利き商店側で作るのは CSV までで大丈夫。

## 共通
- 文字コード：**UTF-8**（BOM はあってもなくてもよい）。区切りはカンマ。1行目は見出し。改行は LF・CRLF のどちらでもよい
- カンマや改行を含む欄は `"…"` で囲む（中の `"` は `""`）
- 日付：`YYYY-MM-DD`（例 `2026-01-05`）
- 金額：**円の正の整数**。カンマ・`¥`・マイナスは付けない（支出か収入かは「種類」で分ける）
- 置き場所：個人のお金の情報なので **Git に入れない**。くらしベースの `自分用/取り込み/`（Git に入らない。2026-11-24 に `自分用/取り込み/` から移した）に置く。例 `C:\Users\kamik\AI開発\暮らしベース\_private\mf_transactions_20261124.csv`。くらしベースのチャットに「置いた」と伝えれば変換する
- ファイル名：`mf_<中身>_<YYYYMMDD>.csv`（中身＝`transactions`・`recurring`）

## 1. 支出・収入・ポイント（獲得分）：`mf_transactions_YYYYMMDD.csv`

| 列 | 必須 | 中身 |
|---|---|---|
| 日付 | ○ | `YYYY-MM-DD` |
| 種類 | ○ | `支出` か `収入` |
| 金額 | ○ | 正の整数（円） |
| カテゴリ | ○ | くらしベースのカテゴリ名（下の一覧）。一覧にない名前は、新しいカテゴリとして作る |
| 内容 |  | お店の名前など（くらしベースの「お店・内容」に入る） |
| 支払い方法 |  | `現金`・`クレジットカード`・`QRコード決済`・`電子マネー`・`口座振替・振込`・`その他`、または空 |
| メモ |  | 自由 |
| 元ID |  | マネフォの明細を区別できる値（あれば）。同じ CSV を2回入れても二重にしないために使う。なければ空でよい |

- **ポイント（獲得分）**：`種類=収入`・`カテゴリ=ポイ活`・`内容`にポイントの名前（例 `楽天ポイント`）。使った分は入れない
- 振替（口座間の移動・カードの引き落とし）は**入れない**（二重に数えないため）

### 今あるカテゴリ（平尾さんのくらしベース。名前が同じなら、そのカテゴリに入る）
- 支出：食費・日用品・交通・住まい・光熱・通信・医療・健康・趣味・娯楽・交際・衣服・美容・その他、投資・家賃・外食費・飲み代•趣味代・コンビニ・医療費・交通費・美容代・経費・水道光熱費
- 収入：給与・副収入・その他の収入、配給・ポイ活・配当金・給料・一時金
- （平尾さんがアプリで名前を変えていることがある。迷ったら上の名前で出してよい）

## 2. 固定費：`mf_recurring_YYYYMMDD.csv`

| 列 | 必須 | 中身 |
|---|---|---|
| 名前 | ○ | 例 `家賃`・`Netflix` |
| 金額 | ○ | 正の整数（円） |
| 周期 | ○ | `毎月`・`毎年`・`毎週` |
| 支払日 | ○ | 毎月・毎年：日にち（1〜31。月末を超えると月末）。毎週：空 |
| 次の支払日 | ○ | `YYYY-MM-DD`（これから来るいちばん近い日） |
| カテゴリ | ○ | 上の一覧と同じ |
| 支払い方法 |  | 上と同じ |

- 固定費は「これからの予定」として登録するもの。過去に払った分は 1 の明細に入れる

## 3. 気をつけること（くらしベースのチャットが確かめる）
