# 友人β の1週間テストのシート（W033・B16・V18）

作成：2026-11-22。期間の予定：公開の翌日から7日間（2026-11-26〜12-02）。
1章は友人にそのまま送れる文。2章からは平尾さん用。

---

## 1. 友人に送る「試してほしいこと」（最初のメッセージのあとに送る）

> 1週間のうちに、できる範囲で次を試してみてください。全部でなくて大丈夫です。
> 1. 今日使ったお金を1件入れる（画面下の「＋」→「支出」）
> 2. これからの予定を1件入れる（「＋」→「予定」）
> 3. カレンダーで、入れた予定が見えるか確かめる
> 4. 毎月払っているもの（スマホ代など）を1件登録する（メニュー →「固定費」）
> 5. 何日か使ったあとに、「振り返り」で今月の使い方を見る
> 6. 最後に、メニュー →「バックアップと復元」で、バックアップを書き出してみる
>
> 迷ったところ、押し間違えたところ、意味が分からなかった言葉があったら、スクショと一言で教えてください。「特になし」も助かります。

## 2. 聞く日と聞くこと

| 日 | 聞くこと（そのまま送れる文） | ねらい |
|---|---|---|
| 1日目の夜 | 「開けた？最初の1件は入れられた？」 | 最初の1件までに止まっていないか（V18） |
| 3日目 | 「ここまでで、迷ったところか、面倒だったところある？」 | 早めに直せるものを拾う |
| 7日目 | 下の5つ | まとめ（W033・B16） |

7日目に聞く5つ：
1. 何回くらい開いた？（毎日／2〜3日に1回／ほぼ開かなかった）
2. いちばん使ったのはどれ？（支出／予定／カレンダー／振り返り／ほか）
3. 迷った・困ったところは？（あればスクショ）
4. 「これがあったら続けて使う」と思ったものは？
5. 記録が消えたり、おかしな表示になったりしたことはあった？

聞かないこと：記録の中身（金額・予定）。バックアップのファイルも、送ってもらわない（不具合の調べに要るときだけ、中身が見えることを伝えて同意をとる。`docs/RELEASE_PREP.md` 5章）。

## 3. 感想の記録のしかた

もらった感想は、1件ずつ下の表に足す（ファイル：`docs/release/FRIEND_FEEDBACK.md`）。
平尾さんは、スクショと文をこのセッションに貼るだけでよい。表に書くのは Claude がやる。

| 列 | 書くこと |
|---|---|
| 日付 | 受け取った日 |
| 画面 | どの画面か（ホーム、＋、カレンダー など） |
| 友人の言葉 | もらった文をそのまま（個人の情報は消す） |
| 種類 | 不具合／迷い／ほしい機能／よかった点 |
| 重さ | P0＝記録が消える・入れられない／P1＝迷って止まる／P2＝あとでよい |
| 対応 | 直した（コミット）／β後に検討／しない（理由） |

P0 が出たら、その日のうちに直して公開し直す（`docs/RELEASE_PREP.md` のロールバックの手順も使える）。
