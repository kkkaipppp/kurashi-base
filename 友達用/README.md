# 友達用（友人β）

2026-11-24 平尾さんの方針で、暮らしベースを「自分用」と「友達用」に分けた。ここは友達に関わるものの置き場（GitHub に上がる。個人のお金のデータは置かない）。

- 公開中の URL：https://kurashi-base-tau.vercel.app/（Vercel の公開版。ビルドは public）
- 友人への案内・テストの頼み方：`docs/release/FRIEND_BETA_TEST_SHEET.md`
- 友人からの感想・不具合の記録：`docs/release/FRIEND_FEEDBACK.md`
- 担当：子チャット「友達用」（公開と、感想・不具合の受付）。アプリのコードを直すのは親チャット（暮らしベース）だけ

自分用（GitHub に上げない）は `自分用/`：家計簿・NISA などの取り込みファイル（`自分用/取り込み/`）と、家計管理（`自分用/家計管理/`）。
